**Kenn die Strecke. Beherrsch das Rennen.** Live-Telemetrie, Rennstrategie, Fahrer-Coaching und dein virtueller
Renningenieur – entwickelt für Gran Turismo 7. Dieses Repository enthält nur die Installationsdateien.

**[Projektseite mit Funktionen und Screenshots](https://altibe.github.io/tracknerd-releases/)** · **[Neueste Version herunterladen](../../releases/latest)** – dort die Setup-Datei (`.exe`) wählen.

## Installation
1. Setup herunterladen. Meldet Edge „unsicher“ / „wird nicht häufig heruntergeladen“: **… → Beibehalten → Trotzdem beibehalten** (das Setup ist noch nicht digital signiert). Dann starten.
2. Windows warnt „Der Computer wurde durch Windows geschützt“ (das Setup ist nicht signiert):
   **Weitere Informationen → Trotzdem ausführen**.
3. Keine Administratorrechte nötig. Haken „Firewall-Regeln anlegen“ drin lassen.
4. Start über die Verknüpfung **TrackNerd**.

## Beim ersten Start
Ein Einrichtungsassistent führt durch PS5-Verbindung, Sprachausgabe (eigener Discord-Bot, optional)
und Online-Liga (Discord-Anmeldung + Einladungscode vom Liga-Admin, optional).
Was jedes Board kann: Board-Auswahl → **? Anleitung**.

Voraussetzungen: Windows 10/11, Microsoft Edge, PC und PS5 im selben Netzwerk.
